# WYD

WYD is a cross-platform mobile application for tracking social availability.

## How to run

1. Download the [Expo Go](https://expo.dev/go) application on your phone.

2. Clone the repository.

3. `cd` into the repository.
4. Install dependencies

   ```bash
   npm install
   ```

5. Start the app

   ```bash
   npx expo start
   ```

   _Alternatively, can run with your preferred package manager (e.g. `bun expo start`).

6. Scan the QR Code via the Expo Go app to launch the application on your mobile device.
